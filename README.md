# ÉcoCinq — École du Cinquantenaire

Base de site institutionnel premium pour l'École du Cinquantenaire à Goma.

## Stack
Next.js 15 · React 19 · TypeScript · Tailwind CSS 4 · DaisyUI · GSAP · Lucide React

## Installation
npm install
npm run dev

Le projet reprend une structure proche du portfolio Issacar, mais avec une direction visuelle institutionnelle : vert profond, ivoire, accent doré, sections pédagogiques et pages dédiées.

Les informations de départ ont été adaptées à partir des informations publiques visibles sur ecocinq.com. Remplace les images de démonstration par les photos officielles de l'école avant mise en production.
